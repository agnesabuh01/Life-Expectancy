# Life Expectancy Data Analysis

##  Project Overview

This project explores global life expectancy trends using data from different countries and years. The analysis focuses on understanding how socioeconomic, health, and demographic factors are associated with life expectancy.

The project was completed using Python and Jupyter Notebook as part of my Data Analytics training.

##  Objectives

The analysis aims to answer questions such as:

- How has life expectancy changed over the years?
- How does life expectancy differ between developed and developing countries?
- Which factors are most strongly associated with life expectancy?
- Which countries have the highest life expectancy?
- Are there countries that perform differently from what their income or schooling levels might suggest?
- How does Africa compare with global averages?

##  Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

##  Key Areas of Analysis

### Life Expectancy Trends
Examined changes in life expectancy over time and compared trends across different groups of countries.

### Factors Associated with Life Expectancy
Explored relationships between life expectancy and factors such as:

- GDP
- Schooling
- Alcohol consumption
- BMI
- Immunization rates
- Adult mortality

### Regional Analysis
Compared life expectancy in Africa with global averages to identify differences and changes over time.

##  Files in This Repository

- `Life-Expectancy-Data-Updated.csv` — Dataset used for the analysis.

##  Insights

The analysis provides insights into the factors associated with differences in life expectancy across countries and highlights patterns in health and socioeconomic outcomes over time.
